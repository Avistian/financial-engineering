Filtrations, Conditional Expectation & Martingales

Reference · print-friendly cheat sheet · Units 011–020 (Year 1 Q2)

The working rules for the language every Q2 unit is written in. Taught in Lesson 011; source Shreve II Ch. 1–2.

The four objects

ObjectIsRead it as
Ωthe sample space; one element ω is a complete future"the set of possible futures"
ℱ (σ-algebra)a collection of subsets of Ω closed under complement and countable union"the questions I can answer" / a partition of Ω into indistinguishable cells (atoms)
Pa measure on ℱ with P(Ω)=1 and countable additivity"mass on events" — single outcomes may have mass 0
{ℱ_t} (filtration)ℱ₀ ⊆ ℱ₁ ⊆ … ⊆ ℱ_T"the growing record of what is known"
"X is ℱ_t-measurable"  =  "X's value is knowable at time t"  =  "X is constant on each atom of ℱ_t"

A process is adapted if X_t is ℱ_t-measurable for every t. Almost surely (a.s.) = true except on a set of probability 0 (so no expectation, price, or hedge is affected).

Conditional expectation — three equivalent descriptions

ViewStatementUse it when
Recipe (finite) E[X|ℱ] averages X within each atom of ℱ computing on a tree, by hand or in code
Definition (general) the unique Y with (1) Y is ℱ-measurable, (2) E[Y·1_A] = E[X·1_A] for all A ∈ ℱ (partial averaging) proving things; continuous time, where atoms have probability 0
Projection (L²) E[X|ℱ] = argmin E[(X−Y)²] over ℱ-measurable Y; the residual X − E[X|ℱ] is orthogonal to every ℱ-measurable variable reasoning about forecasts, signals, R², leakage
E[X|ℱ] is a random variable, not a number — ℱ-measurable, one value per atom. It is a plan for guessing, revealed when the information arrives. Conditioning on an event (E[X|A] = E[X·1_A]/P(A)) is the one that returns a number.

The rules (memorise these)

RuleStatementIn words

Martingales

M adapted, E|M_t| < ∞, and  E[M_t | ℱ_s] = M_s  for all s ≤ t

Best forecast of any future value = today's value: a fair game. Supermartingale: ≤ (drifts down — costs, unfair games). Submartingale: ≥. Checking one step suffices; the tower property extends it to all horizons.

Always name the measure and the filtration. A process can be a martingale under one measure and drift under another — that fact is risk-neutral pricing (unit 015).

Handy checks on this tree: partial averaging on A = {H··} gives 12.725 × ½ = 6.3625 = 50.9/8; tower gives (21.00 + 4.45)/2 = 12.725; the projection minimum is E[(V − E[V|ℱ₁])²] = 83.22 and Var(V) = 110.78 = 83.22 + 27.56. The risk-neutral probability is p* = (1 − d)/(u − d) = ½.

Traps. (1) Treating E[X|ℱ_t] as a number. (2) Conditioning on an event when you meant a σ-algebra. (3) Forgetting that a finer σ-algebra always fits better in sample — which is why leakage = conditioning on a σ-algebra bigger than the one you had, and it always flatters a backtest. (4) Assuming the price tells you the path (σ(S_t) ⊊ ℱ_t when up-then-down and down-then-up land on the same price). (5) Reading "probability zero" as "impossible." (6) Saying "martingale" without naming the measure.
