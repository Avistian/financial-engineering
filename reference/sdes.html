Stochastic Differential Equations: GBM & Ornstein–Uhlenbeck

Reference · print-friendly cheat sheet · Units 014–020 (Year 1 Q2)

How random quantities evolve, and how to solve the two that solve by hand. Taught in Lesson 014; sources Øksendal Ch. 5 and Shreve II §4.4–4.5. Builds on Itô's lemma from Lesson 013.

What an SDE is

dX = a(X, t)·dt + b(X, t)·dW

Drift a = steady pull; diffusion b = size of the random shove. It is an ODE plus a fresh random kick b·dW each step (mean 0, variance dt). "Solving" = a closed form for Xt, or a simulation Xnext = Xnow + a·dt + b·√dt·Z with Z ~ N(0,1).

The one trick. To solve an SDE, apply Itô to a function f(t,X) chosen so the right-hand side has no X left — only t and dW — then integrate. log S for GBM; eθtX for OU.

Geometric Brownian motion (the stock)

ItemValue
SDEdS = μS·dt + σS·dW
Solve viaItô on f = log S ⇒ d(log S) = (μ−½σ²)dt + σ dW
SolutionSt = S0·exp((μ − ½σ²)t + σWt)
MeanE[St] = S0eμt (grows at μ)
Median (typical)S0e(μ−½σ²)t (grows at μ − ½σ²)

The −½σ² is the Itô correction (log curves down). Leave it out of a simulator and prices drift too high.

Ornstein–Uhlenbeck (mean reversion)

ItemValue
SDEdX = θ(m − X)·dt + σ·dW
Knobsm = target level · θ = pull strength · σ = shove size
Solve viaItô on f = eθtX (linear ⇒ no correction) ⇒ d(eθtX) = θm eθtdt + σeθtdW
SolutionXt = X0e−θt + m(1 − e−θt) + σ∫0te−θ(t−s)dWs
MeanE[Xt] = X0e−θt + m(1 − e−θt) → m
Variance(σ²/2θ)(1 − e−2θt) → σ²/2θ
Stationary lawN(m, σ²/2θ)
Half-lifeln 2 / θ (time for the gap to m to halve)

Drift sign is the reversion: X < m ⇒ pull up; X > m ⇒ pull down. Uses of OU: pairs-trading spreads, Vasicek interest rates, any quantity that normalises.

Itô isometry (variance of a stochastic integral)

Var( ∫0t g(s) dWs ) = ∫0t g(s)² ds

Independent shocks, so variances add. This is how the OU variance σ²/2θ is computed.

Existence & uniqueness (intuition)

ConditionPlain meaningGuarantees
Lipschitz |a(x)−a(y)| ≤ K|x−y|bounded steepness — coefficients don't change infinitely fastuniqueness (close paths stay close)
Linear growth |a(x)| ≤ C(1+|x|)drift/diffusion grow no faster than a straight lineexistence for all t (no finite-time blow-up)

Counter-example: dx/dt = x² blows up at t* = 1/x0 (super-linear ⇒ no global solution). GBM (μS, σS) and OU (θ(m−X), σ) are linear in the state, so both are globally well-posed.

Traps. (1) Dropping −½σ² when simulating GBM — prices drift too high. (2) Reading θ(m−X) backwards — pull is toward m. (3) Confusing the mean (→ m) with the wobble (→ σ²/2θ). (4) Expecting the ∫…dW noise term to add drift — it is a martingale, mean 0. (5) Adding an Itô correction to the OU solve — eθtX is linear, fxx=0, no correction. (6) Assuming any SDE has a nice/global solution — a faster-than-linear drift can explode.
